# Push to GitLab

## Quick Command

```bash
git push -u gitlab fix/modernize-flutter-gradle-and-apis
```

## What to Expect

1. It will ask for your SSH passphrase (if you have one)
2. Enter your passphrase
3. Branch will be pushed to GitLab

## Alternative: Push to Both Remotes

```bash
# Push to GitHub
git push origin fix/modernize-flutter-gradle-and-apis

# Push to GitLab
git push gitlab fix/modernize-flutter-gradle-and-apis
```
